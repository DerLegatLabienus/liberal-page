# Multi-Language Support (i18n) — Design

**Date:** 2026-05-16
**Status:** Approved
**Scope:** Full content parity — Hebrew (default, RTL) + English (LTR)

---

## Overview

Add Hebrew/English language switching to the public site. Every user-facing string — UI labels, nav, hero copy, About section, FAQ, Join CTAs — is translated. Parliamentary data (bills, MKs, committees) from the Knesset API is Hebrew-only and stays that way in both locales.

---

## Architecture

**Library:** `react-i18next` + `i18next` (two packages, no other additions).

**Locale files:** `src/locales/he.json` and `src/locales/en.json`. Flat namespace with nested domains (`ui`, `hero`, `about`, `faq`). Both files mirror the same key structure exactly.

**Init:** `src/i18n.ts` configures i18next with both locale files and reads the starting language from `localStorage` (fallback: `he`). It also sets `document.documentElement.lang` and `document.documentElement.dir` immediately to prevent a flash of wrong direction. Imported once in `src/main.tsx` before the React tree mounts.

**Direction:** `useDirection()` already observes `document.documentElement.dir` via MutationObserver — it reacts to language changes automatically. All hardcoded `dir="rtl"` attributes in section components are replaced with `dir={direction}` from the hook.

## Language toggle

A toggle button in `Header.tsx` shows the alternate language name (`EN` when in Hebrew, `עב` when in English). On click:

```ts
const next = i18n.language === 'he' ? 'en' : 'he'
i18n.changeLanguage(next)
document.documentElement.lang = next
document.documentElement.dir = next === 'he' ? 'rtl' : 'ltr'
localStorage.setItem('lang', next)
```

No URL routing for language. `localStorage` persists the choice across refreshes. `i18n.ts` reads it on init.

## Testing

**Existing tests:** Unaffected — `MkCard`, `AddTrackingInput`, `ParliamentDrawer` tests continue to pass. `react-i18next` provides a built-in Vitest mock (`__mocks__/react-i18next.ts`) that returns the key as the translation value.

**New test:** One test in `tests/hooks/useDirection.test.ts` verifying direction updates when `document.documentElement.dir` is changed programmatically (already partially covered — extend with toggle simulation).

---

## Out of scope

- URL-based language routing (`/en/...`) — can be added later with React Router
- Translation of parliamentary card content (Knesset data is Hebrew-only)
- Gallery captions in English (images are Hebrew-language photos — captions stay Hebrew)
- Right-to-left number formatting
